# 眼睛定位与动作检查

定位脚本只需 Python 3 标准库；精灵图行比对脚本还需 Pillow。优先使用当前环境已有依赖，不为此改动用户的全局 Python 环境。

## 漏检案例

原游戏的 `eye_L`/`eye_R` 局部坐标和宽度没变，`head_CTR` 变换约束仍随动画时间移动眼睛世界位置。一次检查在头部坐标系发现约 14 个源骨骼单位额外位移；固定该角色自己的参考控制器后残差降至浮点误差。这个数字属于案例，不是所有模型的标准。

静态拆层角色则可能因不同动作使用不同 gaze 单独移动虹膜/嘴并再次缩放头部；它没有 Spine 控制器，不能套用控制器补丁。

## 三层证据

1. 源关系：原坐标、完整眼图块、原左右宽度/间距、表情附件和开合中心。原左右大小差不是错误。
2. 实际定位：最终动画/约束更新后采集世界位置，逆变换到头部坐标系，记录控制器/脸/眼实际变换。静态拆层记录头层变换前的眼图块中心、宽度、开合和独立虹膜偏移。局部正常而实际漂移时沿父节点、约束和权重查原因。
3. 最终像素/运动：从最终文件解码全部帧，正常大小看脸和状态切换，放大对照辅助。观察开眼→半闭→闭眼→重开、表情切换、头转时是否保持面部关系。

修复非预期额外偏移，保留头动、动作、眨眼和合理开合；不要冻结整人物。原视线动作可有意改变脸部锚点，不能一律按固定锚点判失败。

## 骨骼日志

`check_eye_anchors.py --mode spine` 输入为帧列表或含 `frames` 的对象：

```json
{"state":"running","index":0,"head":{"a":1,"b":0,"c":0,"d":1,"worldX":10,"worldY":20},"eyes":[{"side":"L","world":{"x":13,"y":24},"bone":{"x":3,"y":4,"rotation":0,"scaleX":1}},{"side":"R","world":{"x":17,"y":24},"bone":{"x":7,"y":4,"rotation":0,"scaleX":1}}]}
```

工具逆变换眼睛锚点，默认排除 `look`，对照筛选后第一帧；可指定 `--reference-index`。`--threshold` 单位为源骨骼单位，默认 0.001 针对预期固定锚点；合法有意变化先定义参考/容差，不能为过关而放宽到掩盖用户指出的漂移。

提供 `--skeleton` 时同时核对原 `eye_L`/`eye_R` 局部 x/y/rotation/scaleX，允许源眨眼改变 scaleY。锚点不是可见像素中心；附件偏移、weighted mesh、deform、裁切、实际眼睛大小仍需视觉核对。

## 原图块日志

`--mode patches` 输入每项为：

```json
{"frame":{"state":"running","index":0},"side":0,"source_center":[102.5,120.5],"rendered_center_before_head_motion":[102.5,120.5],"width":27,"opening":0.82,"iris_offset":[0,0]}
```

默认容差 0.2 为源图像素，适配 3 倍渲染中至多 1/6 像素中心取整；其它流水线按实际上界指定容差。检查每眼中心、宽度和独立虹膜偏移，允许开合改变高度。它不是骨骼世界空间检查。

## 必看片段

- 全部动作首尾帧，正常眼和闭眼附近。
- 待机→工作思考→检查→等待/失落→待机，以及实际平台其它切换。
- 左右移动、挥手/笑眼/wink、跳跃及落地。
- 表情眼切换时的上下位置、间距、原宽度差，是否越脸、碰耳朵、穿入刘海。
- 本次若改方向，检查独立视线环绕。

快捷键反馈不能自动推断为 gaze。结合证据简短区分随鼠标方向变化、持续错位、动作切换，不中断独立检查。没有实际读取或操作应用，不能称实机验证。
