# 原素材动画制作

## 来源与外观

搜索原名、作品、SD/chibi/服装名，核对发型、发饰位置/数量、眼睛颜色、制服配件和左右非对称特征。以实际素材说明服装，不能把冬服写成舞台服。官方人设、社区索引、原游戏资源镜像分别标注来源性质。保存原文件不覆盖。

核对板显示原参考、静态候选和脸部放大。记录用户实际接受的范围；不得把一次构图验收扩展为全流程通过。

## 原骨骼

- 检查骨骼、附件、约束、动画名称、版本及 atlas；重用合适的原动画，不臆造接口。
- 记录原静止参考帧的头部、脸部、双眼和控制器变换。setup pose 与动画第零帧可能不同，明确校准采用哪一个。
- 应用动画后做授权的简化改动，更新实际世界变换再渲染；日志取与渲染相同的最终时间点。
- 保留原双眼附件、原宽度差/间距，优先原闭眼、笑眼、wink、悲伤附件及眨眼时间线，不另画替代眼睛。
- 去掉已确认属于 UI 的影子/特效/引导附件，保留人物配饰。左右移动不直接镜像非对称人物。
- 一个共享相机、尺度和基线；确认播放器加载及相机过渡结束后才渲染，检查确有可见人物，避免 blank frame。

## 静态拆层

- 区分人物像素与 UI 光圈/背景，保存清理前后对照。拆头、躯干、四肢时检查关节重叠，避免旋转后颈部断开。
- 头部、完整双眼、眉毛和嘴保有明确的共同坐标关系；用原像素做铰接和变换，不补画人物设定。
- 原完整眼图块包含虹膜、眼白、眼睑和高光。无原眼球层时独立提取/滑动虹膜容易裁切、漂移、改变比例，优先保留整眼图块。
- 调整表情开合前，固定横向中心/间距，定义纵向开合中心或下眼睑锚点。按实际源分辨率说明取整误差，透明包围盒不必完全相同。
- 不把拆层动画称为原游戏骨骼动画。无闭眼附件时如实记录闭眼制作方法与视觉限制。

## 定向返修

保留通过的动作、服装和脸部设计，以最终运动验证修复。不能把一个静态脸贴到所有帧，或逐帧独立缩放来掩盖漂移。

未改视线帧可在组装时保留已注册的两整行，避免再次自动居中/拟合。逐像素确认后声明旧方向审阅只适用于这些未变部分；修改方向则重新审阅。
